# Mobile Sales Analytics Dashboard

## Overview
Interactive Power BI dashboard analyzing 5,000+ mobile sales records across 10 cities to uncover business insights and sales trends.

## Tools Used
- Power BI (DAX, Power Query, Data Modeling)
- Excel (Data Cleaning & Preparation)

## Key Insights
- 3 cities contributed 60% of total revenue
- 2 product categories drove 70% of all transactions
- Replaced 4 static Excel reports with 1 dynamic filterable dashboard

## Dashboard Features
- 6 KPIs: Total Sales, MoM Growth, Customer Ratings, Payment Method Split, City-wise Performance
- Drill-through filters for deep-dive analysis
- Interactive slicers for Date, City, Category, and Channel
